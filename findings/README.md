# findings/

The structured finding model is `../schemas/finding.schema.json`
(status lifecycle, independent-validation flag, judge decision, evidence
references, requires/grants attack-path projection, audit history).

The runtime findings store (one dir per finding on the engagement tree,
PoC scripts numbered inside, hash-chained evidence ledger) is Milestone 4.
Design source: halo-harness-cyber/ENGAGEMENT-MODEL.md.
